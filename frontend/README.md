# Frontend

This folder is for the Next.js app.

## Suggested Use

- `app/` contains routes and pages.
- `components/` stores reusable UI.
- `hooks/` stores shared React logic.
- `lib/` stores API clients and helpers.
- `styles/` stores global CSS.
- `types/` stores TypeScript types.
- `public/` stores images and static files.

## Environment

Copy `frontend/.env.example` to `.env.local` when you start wiring the API URL.
